PowerampOmen leverages real-time event-driven architecture for scalable and adaptive predictive modeling, resource allocation, and decision manager optimization.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PowerampOmen.git`
2. `cd PowerampOmen`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure PowerampOmen, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
